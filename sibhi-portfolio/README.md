# Sibhi Dhayalan — Developer Portfolio

A responsive React + Vite portfolio starter inspired by the structure and clean visual presentation of Anthony Rovira's portfolio. This is an original implementation, not a copy of their source code or assets.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Personalise before publishing

1. Open `src/data.js`.
2. Replace `YOUR_EMAIL@example.com` with your real professional email.
3. Add your real GitHub repository and live demo URLs to each project (`github` and `demo`).
4. Verify every project description matches what you actually built.
5. Add your resume PDF in `public/` (for example `Sibhi-Dhayalan-Resume.pdf`) and add a resume link in the hero if desired.
6. Replace the generic GitHub and LinkedIn profile URLs in `src/App.jsx` with your own profile URLs.
7. If you want a real profile photo, replace the CSS portrait placeholder in `src/App.jsx` with an `<img>` element and add your image under `public/`.
